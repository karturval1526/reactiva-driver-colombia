# ReActiva Driver PRO — publicación desde Android

1. Extrae este ZIP en el teléfono.
2. Abre el repositorio de GitHub.
3. Pulsa **Add file → Upload files**.
4. Sube TODO el contenido, incluyendo `.github` y `.nojekyll`.
5. Haz **Commit changes** en `main`.
6. Ve a **Settings → Pages**.
7. En **Build and deployment**, selecciona **GitHub Actions**.
8. En **Actions**, espera a que termine `Deploy ReActiva Driver PRO`.

URL prevista para tu repositorio:
https://karturval1526.github.io/reactiva-driver-colombia/

## Importante
GitHub Pages aloja el frontend estático; no ejecuta un servidor Node permanente. La carpeta `api/` queda incluida como backend para desplegar posteriormente en un servicio compatible.

Las integraciones reales con Rappi/Picap requieren API/OAuth autorizado por cada plataforma y un backend compatible. No publiques contraseñas, códigos, tokens privados ni claves secretas en el repositorio.
