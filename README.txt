ReActiva Driver Colombia — V10
================================

Esta versión incluye las imágenes de las plataformas DENTRO del ZIP.
Se usan archivos PNG locales para evitar el problema de "imagen rota" que aparecía en Android/GitHub Pages.

Estructura principal:
- index.html
- styles.css
- assets/cover.png
- assets/favicon.png
- assets/portada-reactiva-driver.png
- assets/logos/uber.png
- assets/logos/didi.png
- assets/logos/indrive.png
- assets/logos/rappi.png
- nequi-qr.jpg
- daviplata-qr.jpg

IMPORTANTE:
1. Descarga y descomprime este ZIP.
2. Sube TODO el contenido, incluyendo la carpeta "assets".
3. No subas únicamente index.html.
4. En GitHub Pages, entra a Settings > Pages y usa la rama principal / root.
5. Espera unos minutos y recarga la página.

Las marcas/logotipos pertenecen a sus respectivos propietarios. Esta página no implica afiliación oficial.
