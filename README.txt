SUBIDA RECOMENDADA EN ANDROID:
1. Descomprime el ZIP.
2. Entra al repositorio de GitHub.
3. Sube el archivo index.html directamente a la raíz del repositorio.
4. Si quieres, sube también la carpeta assets y los demás archivos.
5. En Settings > Pages selecciona Deploy from a branch, rama main y carpeta / (root).
6. Guarda y espera la publicación.

IMPORTANTE:
El repositorio debe contener los archivos del sitio. Si el repositorio está vacío, GitHub Pages no puede publicar esta versión.
Las marcas/logotipos pertenecen a sus respectivos propietarios; no se afirma afiliación oficial.
