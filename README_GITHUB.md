# ReActiva Driver PRO — GitHub

Versión organizada para subir desde Android a GitHub Pages.

Incluye PWA, consentimiento individual, conexiones preparadas, análisis, estadísticas, historial, planes, assets y workflow automático de GitHub Pages.

GitHub Pages sirve el frontend. El backend de `api/` no se ejecuta como servidor persistente en Pages y debe desplegarse en un entorno backend cuando se requiera.

Las conexiones externas solo deben implementarse mediante mecanismos oficiales/autorizados y sin almacenar credenciales de usuarios.
